# Assets

## `sample-wallpaper.png`

Bundled verification wallpaper A (Milestone 3+). Teal-and-coral still image labeled “Background Customizer / Milestone 3 sample”.

Assigned to the primary monitor when multiple displays are present.

## `sample-wallpaper-b.png`

Bundled verification wallpaper B (Milestone 4). Purple-and-gold still image labeled “Background Customizer / Milestone 4 sample B”.

Assigned to the second connected monitor (and then cycle A/B for any further monitors).

The shell embeds both files at build time and draws each once per monitor behind the desktop icons.
